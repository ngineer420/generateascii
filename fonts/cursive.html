What Cursive looks like, and when to use it

Cursive is one of 59 FIGlet fonts on this site. FIGlet fonts are not typefaces in the usual sense: each one is a small file describing how to draw every character out of ordinary text symbols, 6 lines tall, so the result is plain text you can paste anywhere a monospace font renders — a terminal banner, a README, a code comment, an IRC channel.

This font draws its characters 6 lines high and joins them using kerned layout, which is the setting the font's own author chose. It has its own lowercase glyphs, so mixed-case text keeps its shape. Wide art is the usual gotcha: a banner that looks right in a full-width terminal will wrap badly in a narrow one, so check the width of your text before you paste it somewhere fixed.
